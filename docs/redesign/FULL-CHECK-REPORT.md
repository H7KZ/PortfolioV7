# Full portfolio check: report

Run 2026-11-01 against the working tree on `fix/v7-more-captures` (production build, local), following [FULL-CHECK.md](FULL-CHECK.md). Nothing is committed, pushed or deployed. Production and `main` were only read (curl, DNS, public APIs). Active probes and load ran against local only.

**Verdict:** no blocker left in the code. Twenty-eight defects were found and fixed in the working tree (table at the end of section 1). What remains is owner work: Cloudflare settings, the privacy wording, `cv.pdf`, dependency bumps, facts only the owner can confirm (section 16). Mobile performance is 100 on the home, résumé and contact pages and 92 to 94 on the blog list and the IONT case study (budget 95, see 1.3).

**Result words:** Passed = checked, nothing wrong. Failed = a defect that stays, with evidence. Fixed = a defect found, fixed in the working tree and rechecked. Skipped = not run, with the reason.

**Environment notes.** Browsers ran one at a time (`--workers=1`): three parallel Chromium instances stall any loopback server on this PC, a plain static server too, so it is the machine. This PC's TLS is intercepted by Norton, so `openssl` shows a fake issuer; the real chain came from crt.sh. WSL is capped at 8 GB; the Docker engine stopped answering twice (once at 7.4 GB used by other containers, once under the ZAP full scan). The owner restarted it the first time. The local CMS is `next dev` behind a fault-injecting proxy, the web is the production build.
